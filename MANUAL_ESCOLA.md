## Como Fazer Login

### Primeiro Acesso

1. Abra o navegador (Chrome, Firefox, Safari, Edge)
2. Digite o endereço: **nexus.betim.gov.br**
3. Clique em "Entrar com Manus"
4. Digite seu email (email da escola)
5. Digite sua senha
6. Clique em "Entrar"

### Esqueci a Senha

1. Na tela de login, clique em "Esqueci minha senha"
2. Digite seu email
3. Você receberá um email com instruções
4. Siga as instruções para criar uma nova senha

### Sair do Sistema

1. Clique no ícone de usuário (canto inferior esquerdo)
2. Clique em "Sair"

## Tela Inicial

Quando você entra no NEXUS, você vê a tela inicial com informações importantes sobre sua escola.

### O Que Você Vê

**Números Importantes:**
- Total de alunos cadastrados
- Mediadores ativos
- Escolas atualizadas
- Atendimentos pendentes

**Acesso Rápido:**
- Botões para acessar as principais funções
- Atalhos para tarefas comuns

### Menu Lateral

No lado esquerdo, você vê o menu com as opções disponíveis:

- **Página Inicial:** Volta para a tela inicial
- **Cadastro:** Para cadastrar alunos
- **Mediadores:** Para ver e gerenciar mediadores

## Cadastro de Alunos

### Adicionar um Novo Aluno

1. Clique em **Cadastro** no menu lateral
2. Clique em **Alunos**
3. Clique no botão **+ Novo Aluno**
4. Preencha os dados:

| Campo | O Que Preencher | Exemplo |
|-------|-----------------|---------|
| **Nome** | Nome completo do aluno | João Silva Santos |
| **Matrícula** | Número de matrícula na escola | 12345 |
| **Série/Turma** | Série e turma | 5º Ano A |
| **Deficiência** | Tipo de deficiência (se houver) | Deficiência Auditiva |
| **Turno** | Período de aula | Matutino |

5. Clique em **Salvar**

### Editar Dados de um Aluno

1. Clique em **Cadastro** → **Alunos**
2. Procure o aluno na lista
3. Clique no ícone de edição (lápis)
4. Altere os dados que precisam ser corrigidos
5. Clique em **Salvar**

### Buscar um Aluno

1. Clique em **Cadastro** → **Alunos**
2. Use a barra de busca no topo
3. Digite o nome ou matrícula do aluno
4. Pressione Enter

## Quadro de Mediadores

O Quadro de Mediadores mostra todos os mediadores que trabalham com alunos da sua escola.

### Visualizar o Quadro

1. Clique em **Mediadores** no menu lateral
2. Clique em **Quadro de Mediadores**
3. Você verá uma tabela com informações de cada mediador

### Informações no Quadro

| Coluna | O Que Significa |
|--------|-----------------|
| **Mediador** | Nome do mediador |
| **Escola** | Escola onde trabalha |
| **Status** | Se está ativo ou não |
| **Data de Admissão** | Quando começou |
| **Alunos Atendidos** | Quantos alunos atende |

### Exportar o Quadro

1. No Quadro de Mediadores, clique em **Exportar CSV**
2. O arquivo será baixado no seu computador
3. Você pode abrir em Excel ou Google Sheets

## Mediadores

### Ver Lista de Mediadores

1. Clique em **Mediadores** no menu lateral
2. Clique em **Mediadores**
3. Você verá a lista de todos os mediadores

### Informações de Cada Mediador

Para cada mediador, você vê:
- Nome
- CPF
- Escola
- Status (Ativo, Inativo, Licença, etc.)
- Data de admissão

### Filtrar Mediadores

1. Use os filtros no topo da página
2. Selecione o status desejado
3. Clique em **Aplicar**

## Dúvidas Frequentes

### P: Como adiciono um novo aluno?

**R:** Clique em **Cadastro** → **Alunos** → **+ Novo Aluno**. Preencha os dados e clique em **Salvar**.

### P: Como edito dados de um aluno?

**R:** Clique em **Cadastro** → **Alunos**. Procure o aluno e clique no ícone de edição (lápis).

### P: Como vejo os mediadores da minha escola?

**R:** Clique em **Mediadores** → **Quadro de Mediadores**.

### P: Como exporto o quadro de mediadores?

**R:** No Quadro de Mediadores, clique em **Exportar CSV**. O arquivo será baixado.

### P: Posso deletar um aluno?

**R:** Sim, mas com cuidado. Procure o aluno e clique no ícone de lixo. Confirme a exclusão.

### P: O que fazer se esquecer a senha?

**R:** Na tela de login, clique em "Esqueci minha senha". Siga as instruções enviadas por email.

### P: Posso acessar o NEXUS pelo celular?

**R:** Sim, o NEXUS funciona em computadores, tablets e celulares.

### P: Quem pode acessar os dados da minha escola?

**R:** Apenas você (secretário da escola) e administradores do sistema. Seus dados estão protegidos.

## Tarefas Diárias

### Manhã (8h-9h)

1. Faça login no NEXUS
2. Verifique se há novos alunos para cadastrar
3. Atualize dados de alunos se necessário

### Tarde (14h-15h)

1. Verifique o Quadro de Mediadores
2. Confirme se os dados estão corretos
3. Exporte o quadro se necessário

### Semanal

1. Verifique se todos os alunos estão cadastrados
2. Atualize dados de alunos que mudaram de turma
3. Confirme status de mediadores

## Informações Importantes

**Dados Sensíveis:** Os dados dos alunos são confidenciais. Não compartilhe com pessoas não autorizadas.

**Atualização:** Mantenha os dados sempre atualizados. Informações desatualizadas podem afetar o acompanhamento dos alunos.

**Backup:** O NEXUS faz backup automático. Você não precisa se preocupar com perda de dados.
