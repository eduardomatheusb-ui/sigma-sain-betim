## Introdução

Como Coordenador de Inclusão, você é responsável por coordenar ações de inclusão educacional, gerenciar mediadores, acompanhar alunos e manter cadastros atualizados. O NEXUS oferece ferramentas para gerenciar essas responsabilidades de forma eficiente.

---

## Acesso ao Sistema

### Login

1. Acesse a URL do NEXUS no navegador
2. Clique em "Entrar com Manus"
3. Autentique-se com suas credenciais
4. Você será redirecionado para a página inicial

### Logout

1. Clique no ícone de usuário no canto inferior esquerdo
2. Selecione "Sair"

## Dashboard Estratégico

Fornece visão consolidada de indicadores-chave sobre alunos, mediadores e escolas.

### Indicadores Principais

- **Total de Alunos:** Quantidade total de alunos
- **Mediadores Ativos:** Mediadores em atividade
- **Escolas Atualizadas:** Escolas com dados recentes
- **Atendimentos Pendentes:** Casos aguardando ação

### Como Usar

1. Acesse **Dashboard → Dashboard Estratégico**
2. Visualize os indicadores
3. Clique em um indicador para ver detalhes
4. Use filtros para refinar a visualização

## Dashboard Gerencial

Oferece visão detalhada de desempenho por escola e mediador.

### Seções Principais

**Métricas por Escola:**

- Identifique escolas com maior demanda

**Mediadores por Status:**
- Acompanhe quantos mediadores estão ativos

- Planeje substituições conforme necessário

**Tendências Temporais:**
- Visualize evolução de indicadores
- Identifique tendências e padrões
- Tome decisões baseadas em dados

## Cadastro de Alunos

### Adicionar Novo Aluno

1. Acesse **Cadastro → Alunos**
2. Clique em "+ Novo Aluno"
3. Preencha os campos:
   - **Nome:** Nome completo
   - **Matrícula:** Número de matrícula
   - **Escola:** Selecione a escola
   - **Série/Turma:** Série e turma
   - **Deficiência:** Tipo de deficiência (se aplicável)
   - **Turno:** Período

4. Clique em "Salvar"

### Editar Aluno

1. Acesse **Cadastro → Alunos**
2. Clique no aluno desejado
3. Altere os campos
4. Clique em "Salvar"

### Buscar Aluno

1. Acesse **Cadastro → Alunos**
2. Use a barra de busca
3. Digite nome ou matrícula
4. Pressione Enter

---

## Cadastro de Escolas

### Adicionar Nova Escola

1. Acesse **Cadastro → Escolas**
2. Clique em "+ Nova Escola"
3. Preencha os dados:
   - **Nome:** Nome da escola
   - **INEP:** Código INEP
   - **Endereço:** Endereço completo
   - **Telefone:** Telefone de contato
   - **Email:** Email institucional
   - **Regional:** Regional de educação

4. Clique em "Salvar"

### Editar Escola

1. Acesse **Cadastro → Escolas**
2. Clique no nome da escola
3. Altere os campos
4. Clique em "Salvar"

---

## Gestão de Mediadores

### Adicionar Mediador

1. Acesse **Mediadores → Mediadores**
2. Clique em "+ Novo Mediador"
3. Preencha os dados:
   - **Nome:** Nome completo
   - **CPF:** CPF (único)
   - **Escola:** Escola de vinculação
   - **Status:** Ativo, Inativo, Licença, etc.
   - **Data de Admissão:** Data de início

4. Clique em "Salvar"

### Alterar Status de Mediador

1. Acesse **Mediadores → Mediadores**
2. Localize o mediador
3. Clique no menu de ações (⋯)
4. Selecione "Alterar Status"
5. Escolha o novo status
6. Clique em "Confirmar"

### Status Disponíveis

- **Ativo:** Mediador em atividade
- **Inativo:** Mediador não ativo
- **Licença Médica:** Afastado por motivo de saúde
- **Afastamento Temporário:** Ausência temporária
- **Desligado:** Mediador desligado
- **Substituído:** Posição ocupada por outro
- **Vaga em Aberto:** Posição não preenchida

## Quadro de Mediadores

Oferece visão consolidada de todos os mediadores e seus vínculos.

### Visualizar Quadro

1. Acesse **Mediadores → Quadro de Mediadores**
2. Selecione filtros:
   - **Escola:** Filtrar por escola
   - **Status:** Filtrar por status
   - **Período:** Período desejado

3. Visualize a tabela com informações

### Exportar Quadro

1. Clique no botão "Exportar CSV"
2. O arquivo será baixado automaticamente

### Informações no Quadro

| Campo | Descrição |
|-------|-----------|
| **Mediador** | Nome do mediador |
| **Escola** | Escola de vinculação |
| **Status** | Status atual |
| **Data de Admissão** | Data de início |
| **Alunos Atendidos** | Quantidade de alunos |

## Relatórios

### Gerar Relatório

1. Acesse **Relatórios**
2. Selecione o tipo de relatório
3. Configure filtros:
   - **Período:** Data de início e fim
   - **Escola:** Filtrar por escola
   - **Mediador:** Filtrar por mediador

4. Clique em "Gerar"
5. Selecione formato (CSV, Excel, PDF)
6. O arquivo será baixado

### Tipos de Relatórios

| Tipo | Descrição |
|------|-----------|
| **Cobertura de Atendimento** | Alunos com/sem mediador |
| **Status de Mediadores** | Distribuição por status |
| **Quadro de Mediadores** | Lista completa |
| **Histórico de Alterações** | Auditoria de mudanças |

## Troubleshooting

### Problema: Não consigo adicionar aluno

**Solução:**
1. Verifique se todos os campos obrigatórios foram preenchidos
2. Verifique se a matrícula já existe
3. Verifique se a escola está cadastrada

### Problema: Erro ao alterar status de mediador

**Solução:**
1. Verifique se o mediador existe
2. Verifique se você tem permissão
3. Recarregue a página (F5)

### Problema: Não consigo visualizar dados de uma escola

**Solução:**
1. Verifique se a escola está cadastrada
2. Verifique se você tem permissão
3. Recarregue a página (F5)

### Problema: Relatório não gera

**Solução:**
1. Verifique se selecionou filtros válidos
2. Tente novamente em alguns minutos
3. Contate suporte se o problema persistir
