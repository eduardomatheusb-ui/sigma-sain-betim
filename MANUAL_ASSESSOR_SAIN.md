## Introdução

Como Assessor SAIN, você é responsável por acompanhar casos de inclusão, mediação e atendimento de alunos em risco. O NEXUS oferece ferramentas para gerenciar esses casos, acompanhar progresso e gerar relatórios.

**Responsabilidades principais:**
- Acompanhar casos de alunos
- Registrar movimentações e atualizações
- Gerar relatórios de acompanhamento
- Colaborar com coordenadores e mediadores

---

## Acesso ao Sistema

### Login

1. Acesse a URL do NEXUS no navegador
2. Clique em "Entrar com Manus"
3. Autentique-se com suas credenciais SAIN
4. Você será redirecionado para a página inicial

### Logout

1. Clique no ícone de usuário no canto inferior esquerdo
2. Selecione "Sair"

## Dashboard Estratégico

Fornece visão consolidada de indicadores-chave sobre alunos, mediadores e escolas.

### Indicadores Principais

- **Total de Alunos:** Quantidade total de alunos no sistema
- **Mediadores Ativos:** Mediadores em atividade
- **Escolas Atualizadas:** Escolas com dados recentes
- **Atendimentos Pendentes:** Casos aguardando ação

### Como Usar

1. Acesse **Dashboard → Dashboard Estratégico**
2. Visualize os indicadores
3. Clique em um indicador para ver detalhes
4. Use filtros para refinar a visualização

---

## Dashboard de Acompanhamento de Casos

Oferece visão detalhada de casos em andamento, incluindo status, responsáveis e prazos.

### Visualizar Casos

1. Acesse **Dashboard → Dashboard de Acompanhamento de Casos**
2. Visualize lista de casos
3. Clique em um caso para ver detalhes

### Filtrar Casos

1. Use os filtros no topo da página:
   - **Status:** Aberto, Em Andamento, Resolvido, Arquivado
   - **Prioridade:** Baixa, Média, Alta, Urgente
   - **Responsável:** Seu nome ou outro assessor
   - **Período:** Data de início e fim

2. Clique em "Aplicar Filtros"

---

## Acompanhamento de Casos

### Criar Novo Caso

1. Acesse **Acompanhamento de Casos → Casos**
2. Clique em "+ Novo Caso"
3. Preencha os dados:
   - **Aluno:** Selecione o aluno (autocomplete)
   - **Tipo de Caso:** Conflito, Inclusão, Atendimento, etc.
   - **Descrição:** Descrição detalhada
   - **Prioridade:** Baixa, Média, Alta, Urgente
   - **Responsável:** Você ou outro assessor

4. Clique em "Salvar"

### Acompanhar Caso

1. Acesse **Acompanhamento de Casos → Casos**
2. Clique no caso desejado
3. Visualize histórico de movimentações
4. Adicione comentários:
   - Clique em "Adicionar Comentário"
   - Digite seu comentário
   - Clique em "Enviar"

5. Altere o status:
   - Clique no campo "Status"
   - Selecione novo status
   - Clique em "Salvar"

### Status de Caso

| Status | Descrição |
|--------|-----------|
| **Aberto** | Caso recém-criado |
| **Em Andamento** | Caso em acompanhamento ativo |
| **Resolvido** | Caso com solução implementada |
| **Arquivado** | Caso finalizado e arquivado |

## Auditoria

Visualize histórico completo de todas as alterações realizadas no sistema.

### Acessar Auditoria

1. Acesse **Acompanhamento de Casos → Auditoria**
2. Visualize lista de alterações
3. Filtre por:
   - **Data:** Data da alteração
   - **Usuário:** Quem realizou a alteração
   - **Tipo:** Tipo de alteração (criação, edição, exclusão)

4. Clique em uma alteração para ver detalhes

---

## Relatórios

### Gerar Relatório

1. Acesse **Relatórios**
2. Selecione o tipo de relatório
3. Configure filtros:
   - **Período:** Data de início e fim
   - **Status:** Filtrar por status
   - **Responsável:** Seu nome ou outro assessor

4. Clique em "Gerar"
5. Selecione formato (CSV, Excel, PDF)
6. O arquivo será baixado

### Tipos de Relatórios

| Tipo | Descrição |
|------|-----------|
| **Casos Abertos** | Casos em andamento |
| **Casos Resolvidos** | Casos finalizados |
| **Histórico de Alterações** | Auditoria de mudanças |
| **Resumo de Atividades** | Atividades por período |

## Fluxo de Trabalho Típico

### Dia a Dia do Assessor

**Manhã (8h-12h):**
1. Acesse o Dashboard Estratégico
2. Verifique casos com status "Aberto" ou "Em Andamento"
3. Priorize casos urgentes
4. Atualize status conforme necessário
5. Adicione comentários de acompanhamento

**Tarde (13h-17h):**
1. Continue acompanhamento de casos
2. Colabore com coordenadores e mediadores
3. Gere relatórios conforme solicitado
4. Arquive casos resolvidos

### Exemplo: Acompanhar Caso de Aluno em Risco

1. **Recebimento:** Caso é criado no sistema
2. **Análise:** Você visualiza detalhes do aluno e situação
3. **Ação:** Você atualiza status para "Em Andamento"
4. **Acompanhamento:** Você adiciona comentários regularmente
5. **Resolução:** Você altera status para "Resolvido"
6. **Encerramento:** Você arquiva o caso

## Troubleshooting

### Problema: Não consigo visualizar um caso

**Solução:**
1. Verifique se o caso existe (procure na lista)
2. Verifique se você tem permissão (contate admin)
3. Recarregue a página (F5)

### Problema: Erro ao salvar comentário

**Solução:**
1. Verifique se digitou o comentário
2. Verifique sua conexão com a internet
3. Tente novamente em alguns minutos

### Problema: Relatório não gera

**Solução:**
1. Verifique se selecionou filtros válidos
2. Tente novamente em alguns minutos
3. Contate suporte se o problema persistir

### Problema: Não consigo alterar status de caso

**Solução:**
1. Verifique se você é o responsável pelo caso
2. Verifique se o caso não está arquivado
3. Contate admin se o problema persistir

## Dicas Importantes

**Salve seu trabalho regularmente:** Clique em "Salvar" após cada alteração importante.

**Use comentários:** Adicione comentários detalhados para que outros assessores entendam o contexto do caso.

**Atualize status:** Mantenha o status do caso atualizado para facilitar o acompanhamento.

**Gere relatórios:** Gere relatórios regularmente para acompanhar progresso e identificar tendências.
