# Guia Rápido — Quadro de Mediadores

**Uma página de referência rápida para gerenciar o quadro de mediadores no NEXUS**

---

## O Que É o Quadro de Mediadores?

O Quadro de Mediadores é uma visualização consolidada de todos os mediadores, suas escolas, status e alunos atendidos.

---

## Acessar o Quadro

1. Clique em **Mediadores** no menu lateral
2. Clique em **Quadro de Mediadores**
3. Você verá uma tabela com todos os mediadores

---

## Informações no Quadro

| Coluna | O Que Significa |
|--------|-----------------|
| **Mediador** | Nome do mediador |
| **Escola** | Escola onde trabalha |
| **Status** | Ativo, Inativo, Licença, etc. |
| **Data de Admissão** | Quando começou |
| **Alunos Atendidos** | Quantos alunos atende |

---

## Filtrar Quadro

1. Use os filtros no topo:
   - **Escola:** Filtrar por escola
   - **Status:** Filtrar por status
   - **Período:** Período desejado

2. Clique em **Aplicar Filtros**

---

## Exportar Quadro

1. Clique em **Exportar CSV**
2. O arquivo será baixado
3. Abra em Excel ou Google Sheets
4. Você pode imprimir ou compartilhar

---

## Status de Mediador

| Status | Significado |
|--------|-----------|
| **Ativo** | Mediador em atividade |
| **Inativo** | Mediador não ativo |
| **Licença Médica** | Afastado por motivo de saúde |
| **Afastamento Temporário** | Ausência temporária |
| **Desligado** | Mediador desligado |
| **Substituído** | Posição ocupada por outro |
| **Vaga em Aberto** | Posição não preenchida |

---

## Alterar Status de Mediador

1. Acesse **Mediadores → Mediadores**
2. Localize o mediador
3. Clique no menu de ações (⋯)
4. Selecione **Alterar Status**
5. Escolha o novo status
6. Clique em **Confirmar**

---

## Adicionar Novo Mediador

1. Clique em **Mediadores → Mediadores**
2. Clique em **+ Novo Mediador**
3. Preencha os dados:
   - **Nome:** Nome completo
   - **CPF:** CPF (único)
   - **Escola:** Escola de vinculação
   - **Status:** Ativo, Inativo, etc.
   - **Data de Admissão:** Data de início

4. Clique em **Salvar**

---

## Visualizar Detalhes de Mediador

1. Clique em **Mediadores → Mediadores**
2. Clique no nome do mediador
3. Você verá:
   - Informações pessoais
   - Histórico de status
   - Alunos atendidos
   - Movimentações registradas

---

## Dicas Rápidas

✅ Exporte o quadro regularmente para ter backup  
✅ Use filtros para encontrar mediadores rapidamente  
✅ Atualize status quando houver mudanças  
✅ Verifique vagas em aberto regularmente  
✅ Registre movimentações para manter histórico  

---

## Informações Importantes

**Dados Únicos:** O CPF de cada mediador deve ser único no sistema.

**Status Importante:** Mantenha o status atualizado para refletir a situação real.

**Histórico:** Todas as alterações de status são registradas automaticamente.
